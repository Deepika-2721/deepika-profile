# Deepika Maragathavel — Personal Portfolio

A responsive, single-page personal portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `profile-website` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Included interactions
- Light/dark theme toggle (remembers the selected theme in the browser).
- Responsive navigation menu.
- Scroll-triggered reveal animations.
- Hover zoom on photographs and cards.
- Family reveal: the heart cover reveals the supplied group photograph on hover or tap; select a family label to reveal its note.
- Hobby cards open an accessible detail lightbox.
- Jacky and Ceaser have a dedicated heart-cover flip card; the supplied photo is brightened and included locally.
- Back-to-top button and smooth anchor scrolling.
- Reduced-motion support.

## Personalise later
- Add your LinkedIn profile URL in `index.html` (search for `linkedin-placeholder`).
- Some interest and travel images are illustrative remote references; the personal portrait, family photograph and pet photograph are included locally.
- Review the family descriptions and edit the `data-description` values on the five family buttons if you want more personal characteristics.
- Your professional portrait, family photograph, brightened Jacky and Ceaser photograph, and PSIog logo are included locally.

## Typography
The design uses Bodoni Moda, Italiana, Parisienne, Syne and DM Sans from Google Fonts. An internet connection is needed to load web fonts and the illustrative remote images. The name in the hero uses the exact Unicode italic lettering requested.
